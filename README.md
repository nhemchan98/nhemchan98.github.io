# Nhem Chan — Portfolio v4

Professional personal portfolio built with **Astro + Tailwind CSS + TypeScript**.

## v4 upgrades

- Keeps the current dark premium design
- Uses Nhem Chan's uploaded profile photo
- Professional technology icons
- Visual project cards with project artwork
- Project detail pages
- Responsive mobile navigation
- Hover and reveal animations
- Reduced-motion support
- GitHub Pages deployment workflow
- SEO / Open Graph metadata
- Public GitHub integration

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Target:

`https://nhemchan98.github.io`

Push to `main`, then enable **GitHub Pages → GitHub Actions**.
